# About Burn Station
This is a legitimate open-source dApp for burning Solana tokens and reclaiming rent.

# Security
- Non-custodial: Your private keys never leave your wallet
- All transactions require explicit user approval
- Source code: https://github.com/LegendaryTunzeverywhere/burn-station
- All RPC calls are proxied server-side to protect API keys

# Platform Fee
- 1% of reclaimed rent goes to platform maintenance
- Fee is clearly shown before transaction approval
